开始之前

几个你可能
关心的问题。

软件免费吗？

软件免费开源。模型服务与所需 API Key 由你提供，服务费用取决于你的选择。项目源码采用 Apache-2.0，第三方组件保留各自许可。

会自动发送微信消息吗？

不会。回复建议可以复制，由你自行决定是否使用。当前版本不操作微信输入或发送。

需要什么电脑和微信版本？

面向 Windows 10/11 x64 和 Windows 微信 4.x。正式安装包自带 Node.js、Python、FFmpeg 等运行环境；AI 功能仍需配置自己的模型服务。具体兼容范围以发行说明为准。

可以把聊天记录发给你们排查问题吗？

反馈问题前，请先移除聊天正文、联系人、账号标识、凭据与本机配置。优先提供虚构的最小复现，不上传真实聊天数据库或私人运行资料。
