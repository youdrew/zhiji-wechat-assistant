## Reproduce

Extract the exact source archive into a clean directory. In a process using the above portable toolkit's `bin` first in PATH, change into `ffmpeg-7.1`, then run `sh /path/to/build-ffmpeg.sh`. The script creates only a relative temporary directory and generated build files in this source tree, configures FFmpeg and builds/strips `ffmpeg.exe`. No system environment or compiler installation is required. Make parallelism may be adjusted without changing configured functionality.

All compile sources use relative paths. Debug information is disabled, the prefix is the neutral `/usr`, path mappings are relative, and the executable is stripped. The build disables GPL, nonfree, version3, optional external-library autodetection, network protocols, hardware acceleration, capture devices, postprocessing, ffplay and ffprobe. Built-in CPU decoders, encoders, demuxers, muxers and applicable filters remain available without optional third-party codec libraries. The actual build configuration is recorded in ffmpeg-buildconf.txt.
