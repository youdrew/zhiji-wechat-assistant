安全与数据说明

数据流向

外部 AI 客户端通过 MCP 读取到的资料，会先进入该客户端。该客户端随后可能把它配置的模型服务商处理这些内容， 处理过程发生在本机之外。本页的开关与授权只约束知己这一侧提供什么，不约束外部客户端之后如何使用或转发。

已经提供给外部模型的内容无法收回。撤销授权或删除客户端只阻止后续读取。

提示注入

聊天内容来自联系人，其中可能包含刻意构造的文字，试图诱导外部 AI 客户端去调用工具（例如读取更多资料或修改资料）。 知己侧的授权检查不受这些文字影响，但外部客户端是否遵循自身安全策略取决于该客户端。

本机进程边界

同一 Windows 用户下的进程原则上可以读取该用户可访问的本机文件。MCP 的配对与授权约束的是受支持的 MCP 调用与误用，不提供操作系统级的恶意程序隔离。

凭据与确认

客户端凭据只在创建或重新生成时展示一次，之后不再回显；知己只保存校验值，不保存明文。

已保存模型密钥的明文不能通过 MCP 读取或导出。删除整个账号、清空本机数据等高影响删除，每次都需要在本机确认界面单独确认。
