# 免费开源版与后续 Pro 规划

更新：2026-11-02（Asia/Tokyo）。本文说明首版免费开源交付范围；后续 Pro 仍为规划，不代表已提供下载、商业授权或功能验收。

## 版本边界

| 项目 | 免费开源版 2.0.0 | 后续 Pro |
| --- | --- | --- |
| 部署 | 一台 Windows 电脑，微信与客户端在本机运行 | 规划由用户自备两台电脑，页面机与微信节点分开；配对、同步和远程控制仍待实现与验收 |
| 模型 | 用户自行配置模型服务与所需 API Key，可连接云端、本机或局域网兼容服务 | 同样由用户自行配置，复用 Core 模型设置与网关 |
| 聊天查看与媒体 | 提供 | 复用免费版 |
| 知己分析、记忆、助手、分析与建议 | 提供 | 复用免费版 |
| 自我剖析、时间线、表达知识库、聊天试用 | 提供；依恋问卷因分发许可未闭环暂缓 | 复用免费版中已完成许可核查的能力 |
| 外部聊天截图／录屏导入 | 提供，用户手工选择素材并核对识别结果 | 复用免费版 |
| 多模型、用量、开发者调用记录、MCP | 提供；MCP 不含微信发送工具 | 复用免费版，外部插件能力另行设计 |
| 微信发送 | 不含插件、SDK 源码／运行文件、执行器或 MCP 发送工具 | 以闭源外部插件提供；已有实验不代表双机 Pro 已交付 |
| 好友朋友圈抓取 | 不提供 | 待做 |
| 好友社交媒体抓取 | 不提供 | 待做 |

“单机运行”不要求用户自建模型服务器，也不要求第二台电脑。使用云端模型时，相关文本或图片会发送到用户选择的服务；本地优先不等于离线。两个版本均不提供模型账号、预置 token 或生成模型权重。

## 首版免费交付

首版保留当前免费功能的最新实现，不把自我剖析、模型设置、用量或 MCP 改为付费功能。回复候选供用户复制和自行使用；主聊天页和 MCP 均不操作微信发送。手工导入其他软件的聊天素材与自动登录、抓取软件账号是不同功能，本版只提供前者。

微信发送相关插件、第三方发送 SDK、原生发送执行器、个人许可证及本机运行目录不进入公开源码或免费安装包。通用插件宿主、模型网关、只读微信数据源和免费业务插件继续开源。上游读取依赖及其许可不会因为删除发送能力而移除。

## 后续 Pro 仍需完成

- 明确外部插件的交付、独立安装／更新、依赖与授权方式；定价、是否套装或单独购买另行确定。
- 完成页面机与微信节点的配对、连接认证、传输保护、增量同步、断线恢复和账号隔离。
- 对发送行为另行验证账号与收件人核验、草稿保留、幂等、结果不确定处理、停止和本机审计。
- 分别设计朋友圈与社交媒体的数据来源、用户操作范围、许可与兼容验收；目前不承诺平台覆盖或上线时间。
- 在正式提供相关插件前完成依赖许可及实际发行条款核查；实验性实现与第三方许可不能代替完整产品验收。

原研究中讨论的 Pro 单机形态和单独买断方式不属于本次已确认的公开发行范围。当前产品方向是免费版单机、Pro 双机；后续变化应先更新本文和实际交付说明。

## 免费版发布验收

- 公共源码、每个新增提交和最终解包内容均不含微信发送插件、相关 SDK、执行器与个人授权文件；不能仅靠“默认停用”。
- 主聊天仅保留可复制草稿；MCP 工具列表与运行能力中没有微信发送入口。
- 只从已审核的免费源码构建；不复制开发者的聊天、联系人、媒体、分析结果、token 或个人配置。
- 作者署名、GitHub、博客、邮箱及第三方来源署名按维护者明确授权和既有许可保留。
- 通过[发布记录](releases/2.0.0.md)中的功能、安装、隐私和许可证核对后，才公布正式附件；未验收的项目明确记录，不写成已发布。

当前逐项状态见[需求待办清单](requirements-todo.md#editions)，普通用户安装与数据流向见[安装与使用](getting-started.md)。
