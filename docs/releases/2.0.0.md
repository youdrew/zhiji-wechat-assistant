# 知己微信助手 2.0.0

2.0.0 为首个免费开源安装版本；下载以官方发布页实际公布的附件为准。

本文说明本版功能与边界。实际附件、源码提交、SHA-256、程序签名状态和验证结果以该次发行公告为准；源码与合成测试不替代全部真实场景验收。

## 安装与开始使用

- 面向 Windows 10/11 x64、Windows 微信 4.x。
- 一台 Windows 电脑即可运行；模型服务与所需 API Key 由用户自行提供。
- 安装包名称：`Zhiji-WeChat-Assistant-2.0.0-Setup-x64.exe`，内置运行环境，无需另装 Node.js、Python 或 .NET。
- 登录微信，打开知己微信助手，在模型设置中配置自己的模型服务并测试连接，再添加好友或群聊。
- 模型账号、API Key 和生成模型权重不随软件提供。图片理解需要支持图片输入的模型。
- 从[2.0.0 官方发布页](https://github.com/youdrew/zhiji-wechat-assistant/releases/tag/v2.0.0)下载安装包、校验文件及验收说明。

## 主要功能

- 浏览单聊、群聊和可读取的聊天媒体，按关键词、日期查找记录。
- 从聊天中整理关系记忆，确认、编辑、删除并回查原文。
- 查看好友概述、聊天分析和关系趋势，向聊天助手询问交流建议。
- 按联系人开启“分析与建议”，获取消息解读和三条可复制回复。
- 导入其他软件的单聊截图或录屏，识别、核对后保存。
- 自我剖析、经历时间线、性格与三观分析、本人表达知识库与聊天试用。
- 多模型用途设置、本机语义检索、可选判断模型准备与影子评估、模型用量和调用记录。
- 授权本机 AI 客户端通过 MCP 读取资料、运行分析和管理本地内容。
- 关于页提供作者的[个人博客](https://eugenepage.com/)和[电子邮箱](mailto:youdrewxuan@icloud.com)。

## 数据与兼容

- 个人设置、关系记忆和运行资料保存在本机，不随安装包分发。使用模型服务时，所需聊天文本、摘要或图片会发送到你配置的服务。
- 安装器按当前 Windows 用户安装；卸载仅删除本次安装的程序文件，保留运行后生成的资料及其他未随包分发的文件。重装应使用原安装位置。
- 当前版本关闭应用内自动更新。后续升级以官方发布页公告和新安装包为准。
- 保留既有应用 ID、内部插件 ID、数据路径和 `KnowYourFriends.exe` 等兼容标识；展示名称更新不会迁移或清理原开发版数据，也不会将开发目录资料自动导入安装版。
- 本版不包含微信发送插件、相关 SDK、执行器或 MCP 发送工具。回复只能复制后自行使用；不提供朋友圈或社交媒体抓取。
- 依恋问卷的软件分发许可尚未确认，首版暂不交付该问卷分支；其他自我剖析功能保留。来源和核查范围见[量表来源与许可](../scale-sources-and-permissions.md)。
- AI 分析可能有误，本地可读取的记录不代表手机端完整历史或实时同步。详细说明见[安装与使用](../getting-started.md)。
