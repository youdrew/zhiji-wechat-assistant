# 外部聊天导入

将其他软件的聊天截图或录屏整理为可核对、可搜索、能回查来源的逐条记录。来源名称由用户自由填写，没有预置的软件名单。导入入口、核对和保存由软件核心提供，默认附带的“外部聊天识别”插件负责调用视觉模型。保存不会启动知己分析，也不会发送消息。

当前实现已通过合成流程测试及有限的本机录屏样本验证；不同来源整段素材的文字、发送者、气泡边界、顺序及漏识别质量仍需验收。识别结果只覆盖素材中实际可见的范围，不代表完整聊天历史。

停用“外部聊天识别”插件后，好友聊天顶部的“外部聊天”入口会隐藏；已经打开的窗口与核对草稿保留，识别功能显示不可用。重新启用插件后入口恢复，可继续处理资料。

## 开始导入

1. 在好友聊天顶部点击“外部聊天”，打开属于这位好友的独立窗口，主聊天页保持原样。窗口标题显示好友名称，顶部只有“聊天记录 / 导入任务”和“导入聊天”；关闭窗口即回到聊天。窗口不增加好友侧栏，也不要求重新选择好友。首次导入时，后台建立与当前微信账号和好友明确对应的资料，不按昵称合并。
2. 窗口只有“聊天记录”和“导入任务”两个主标签。默认浏览当前好友的聊天；点击“导入聊天”，填写来源名称并添加截图或录屏。来源为最多 80 个字符的非空文字，可复用这个好友已有的来源，不会按软件名称限制支持范围。
3. 软件默认使用当前好友对应的来源会话；已有同来源会话时默认追加。一般不必填写账号和会话标识，需要区分本人其他账号或同来源不同会话时，展开“更多选项”更改。本次导入备注也放在更多选项中；已有来源会话的说明会继续保留，均与聊天正文分开保存。
4. 一批只对应这位好友的一段来源会话。截图按选择顺序添加；录屏可选择从较早消息滚动到较新消息，或相反方向。点击“开始导入”后，软件上传素材并自动开始后台整理；补充素材请另起一批。
5. 识别统一使用“模型设置”中的主模型，任务页“更多”中显示实际模型名称和连接地址。每个任务只有一个页面：顶部一行显示识别进度，或停止、失败的原因与“继续未完成的部分”；识别出的消息随即出现在下方，可边识别边核对，识别完成后按批次保存。“核对记录”属于具体任务，不另占主标签；原素材从任务页的“素材”查看。

每个窗口始终属于打开时的好友。切换主聊天页的好友不会将已有窗口悄悄改为另一位好友；从新好友顶部再进入时，打开对应的外部聊天窗口。缺少有效好友上下文时，不默认打开第一位好友，也不展示全部好友的资料。

素材上传、任务提交或核对编辑尚未保存时，关闭窗口会先提示保留。已启动识别后，关闭独立窗口不会停止后台任务；退出软件后可从任务列表继续。退出软件时若选择保留任一外部聊天窗口，本次退出也会取消。

## 首版素材限制

| 项目 | 支持范围 |
| --- | --- |
| 截图 | 静态 PNG、JPEG、WebP；普通截图与长截图 |
| 录屏 | 可解码的 MP4、MOV、WebM，每批最多一段，可与截图混用 |
| 数量 | 每批最多 20 份素材 |
| 文件大小 | 单文件最多 128 MiB，界面显示为 128 MB |
| 录屏时长 | 单段最多 3 分钟，超出请分批 |
| 分辨率 | 截图最多 8000 万像素，录屏最多 1600 万像素，最短边至少 32 像素 |

长截图会拆成有重叠的证据画面，录屏会抽取有限画面。快速滑动、遮挡、录制不连续和跨画面的长气泡可能产生漏识别或疑点，不能恢复没有录到的内容。首版没有手工裁剪、补录、合并或拆分气泡工具。

## 后台怎样整理

后台先保守选取清晰且有重叠的画面，小字放大后逐帧转录，再自动处理能够依据画面确认的问题：

- 明确的日期分隔条、顶部标题和输入栏等界面文字不作为聊天正文。真正发在气泡里的日期仍作为消息保留；不能确定的内容继续核对。
- 结合气泡位置和画面的滚动对应关系，关联同一气泡的多次出现。相同正文不会直接合并，两条真实的“哈哈”仍可分别保留。
- 同一气泡有截断画面和完整画面时，优先采用完整观察，核对页也优先展示对应证据；原来的观察和来源画面继续保留。
- 对仍然模糊、截断或相邻识别不一致的内容，在有限复核次数内，每次最多结合三份相关画面补看。复核不能确认的部分继续留作疑点，不凭上下文补写。

后台处理不替代批次确认保存，也不把机器复核标成人工逐条核对。人工已编辑、已核对和已保存的内容受到保护；重新识别不会覆盖这些内容，差异继续交给你核对。

## 模型与数据去向

先在应用设置中配置能够读取图片的模型，并启用“外部聊天识别”插件。插件使用核心统一模型路由；截图或录屏抽出的画面会发送到所配置的模型服务地址。使用远程模型时，画面会离开本设备；模型声明支持图片也不等于识别质量已验证。

页面更多操作中的“模型调用”查看当前好友的调用、耗时和已报告用量。服务没有报告的 token 数显示为“—”，不会当作零消耗。

原素材副本、证据画面、好友、候选及正式记录保存在本机数据目录 `core/external-chat/`；源码开发环境对应 `.local/core/external-chat/`。这些私人资料不应提交到代码仓库。

## 核对与部分保存

核对页左边是原画面，右边按聊天样式列出识别出的全部消息，可切换只看“疑点”。有疑点的消息只把气泡标成黄色，不再在下方附加说明，鼠标停在气泡上可看到原因；每个画面自身的识别备注显示在原画面下方。无疑点记录不要求逐条点击确认。

- 上下滚动聊天时，左侧原画面跟随当前位置切换并框出对应气泡；同一气泡出现在多个画面时，可在原画面下方翻看。点击原画面打开完整录屏或原截图。
- 打开任务时滚到第一处疑点。单击气泡即在原位编辑，气泡保持原来大小；改不改都可以，点到别处离开（或按 Enter）即视为确认，黄色气泡恢复正常颜色。Shift+Enter 换行，Esc 放弃编辑且不确认。
- 右键气泡弹出“确认”和“删除”。删除的消息立即从界面移除，几秒内可点“撤销”。删除、修改、确认和拖动都可以按 Ctrl+Z 从最近一次起逐步撤回；正在气泡里打字时 Ctrl+Z 仍是文字撤回。已保存的记录不能撤回，请在聊天记录中更正。
- 未保存的气泡可以按住拖到正确的位置，松手处显示插入线。调整后的位置在保存、重新识别和聊天记录中保持。发送者不明的气泡右键选择“我发的”或“对方发的”；气泡左右已表明发送者，已识别的发送者或可见时间有误时，保存后在聊天记录中点气泡更正。
- 正文里还有看不清的字（□）时不能确认，改好后离开即可；已经修改但暂未能确认的内容会保留为“编辑待确认”。界面提示或非消息内容可直接删除。

- 正文和发送者明确但缺时间时，可以按未知时间保存。原来显示“昨天”或不完整日期就保留原标记，不自动补年份，也不把录屏播放位置当成发送时间。
- 明确的系统通知显示为“系统通知”，不强行归到本人或好友名下；仍有文字或内容疑点的通知照常核对。
- 发言人不明、文字不清晰或正文截断时，继续留在任务中。截断的气泡可以补全后确认，也可以按画面中可见的部分直接确认。
- 相同文字可能是重复画面，也可能是再次发言。疑似重复的气泡确认即作为另一次真实发言单独保存，删除即视为重复；重新识别已保存的同一气泡时，确认保留已有正文与人工修正。
- 点击右上角“保存 N 条”时，只保存无疑点和已解决疑点的范围。剩余疑点继续留在原任务，重复保存不会重复入库。

之后可继续核对并补充保存，记录按可核对的素材顺序归位，未保存位置显示缺口。跨批次共享记录用于对齐顺序；缺少重叠证据时按导入分组展示并提示，顺序冲突会标记不确定，不能据此推断准确时间。

## 浏览、停止与修订

从好友进入“聊天记录”标签，聊天按气泡样式显示，可按来源、批次筛选及关键词查找；点击气泡查看仍保留的原画面，或更正记录。图片和表情会从画面中截取显示的部分，作为该消息的图片保存（清晰度取决于录屏或截图，不是原图）；语音、视频气泡仅保存画面中可见的信息，没有取得原件就不能当作可播放附件。

切换好友或关闭导入页面后，后台整理继续。点击任务页进度条旁的“停止”会保留已完成画面和已提交的核对编辑；失败后“继续未完成的部分”只重试尚未完成的画面。退出应用后任务不继续执行，重新打开后由你手动继续。导入使用后台模型调度，交互助手优先。

“更多 → 重新识别”保留已保存记录与人工修正，新差异先进入核对；可保留原版本，或在正式聊天中编辑已保存记录。首版继续或重新识别仍要求原素材与必要证据可用。原素材已清理时，需要新建导入批次重新选择素材，不能向已开始识别的旧批次添加文件。

任务的“更多”可以修改关联或撤销本批保存。共享消息不会因撤销一个批次而被误删；保存后的正文修正保留版本。一段来源会话含多个批次时，单批修改不会默默迁移全部来源，需要给拆分批次选择不同的会话标识。

## 删除导入任务

每个导入任务旁直接显示“删除”。运行中的任务需要确认“停止并删除”，软件会先停止，再删除任务。

删除任务会将它移出任务列表，未保存内容不再继续核对；已经保存的聊天、原素材副本和证据画面仍然保留。此操作是归档任务，不是清空本机数据，也不撤销已经保存的聊天。一个来源的任务全部删除、且从未保存过聊天时，这个来源不再出现在聊天记录、来源标签和导入选项中；用相同来源再次导入会恢复它。需要撤销本批保存或释放素材空间时，分别使用任务“更多”中的对应操作。

## 分项清理

“更多 → 查看影响”先展示清理范围、依赖和影响，再分别处理：

| 操作 | 影响 |
| --- | --- |
| 原素材副本 | 清理本软件留存的截图／录屏，保留正文与未清理证据；完整录屏不能再回放或补抽画面 |
| 证据画面 | 保留正式正文，但对应画面不能再回查 |
| 导入任务 | 也可直接从任务列表删除；停止后归档，未保存内容停止核对，保留正式记录、原素材、证据和未保存缺口标记 |
| 本批正式记录 | 撤销本批保存关联，其他批次仍引用的共享消息保留 |

未完成任务所需的素材和跨批共享素材会阻止直接清理。放弃一个未完成任务时，可先停止并移出任务列表，再单独处理素材。清理只针对本软件副本，不删除最初选择的文件或来源软件里的聊天。
