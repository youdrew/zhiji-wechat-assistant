# 聊天媒体与 AI 上下文

知己微信助手新增代码采用 Apache-2.0。本功能优先只读使用微信本地已存在的内容，不向微信发送消息或修改微信源文件。表情包本地不可读时，可按需从消息自带的微信官方 CDN 地址取回，经校验后缓存在本机；不批量下载聊天历史。

## 聊天中的显示

- 图片显示懒加载缩略图，点击在独立窗口查看可读取的原图，可拖动窗口、放大缩小、双击切换原始大小与适应窗口，按 Esc 关闭；仅有缩略图时使用可用版本。不同图片可以同时打开，再次点击同一图片会回到已开的窗口。切换会话或账号时关闭图片窗口。
- 表情包（消息类型 47 / 11000）显示紧凑、透明背景的原始图像，保留 GIF / WebP 动画，懒加载，点击可在独立窗口查看。先读取当前微信账号的表情文件或本软件缓存，支持微信加密表情缓存，以及按表情资源索引读取已下载的商店表情包。消息没有下载地址时也可使用这些本地原件；本地不可读时，仅允许指定微信表情 CDN 域名及表情路径，通过 HTTPS 按需下载。链接过期、校验不符或不可读时显示“表情暂不可用”。
- 语音显示时长与播放气泡，点击后在本地把 SILK 转为 WAV。同一时间播放一条，切换会话时停止。
- 微信消息中已保存的语音转写，注明“微信转写”并显示在气泡下方。不执行微信 GUI 转写，也没有新增 ASR。
- 视频显示封面与时长，点击才加载播放内容；本地 HTTP 支持 Range，拖动进度不需要把整个视频装入内存。
- 文件未下载到电脑、被微信清理、解密凭据缺失或编码不支持时，保留消息并显示不可用状态，不伪造原件。

首次读取媒体时，按需补齐当前账号的图片、表情解密信息及语音或表情资源数据库读取准备；不增加普通文字聊天的启动必需数据库。专用解密信息只在内存中使用，首次读取可能需要等待对应媒体库快照准备。

网页与公众号分享、带网页地址的小程序分享会显示为链接卡片，保留消息自带的标题、摘要和来源，点击用默认浏览器打开。没有有效网页地址时仍显示卡片并注明“链接地址不可用”；不会猜测网址或自动加载外部封面。普通文字中的 HTTP / HTTPS 网址也可点击。小程序专用页面与视频号卡片的完整适配仍未包含。

## 存储设置

在设置的“媒体保存”中选择：

- **复制留存（默认）**：查看或分析媒体时，将可用内容保存到本软件按账号隔离的本机媒体目录；后续优先读取已留存内容。不立即扫描或复制全部聊天历史，也不保证未读取的媒体已备份。重新切回引用模式不会删除已有留存。
- **引用微信文件**：保存关联，按需读取微信本地文件。媒体原件不批量复制；语音播放及视频封面等派生内容允许缓存。已经留存的内容仍可优先读取。

默认值适用于尚未保存媒体模式的账号；已有明确设置保持不变。留存文件占用本机磁盘，不受下方缓存上限限制。首次复制可能增加读取耗时，后续读取可减少对微信媒体原件的依赖；实际速度需要实测。媒体文件留存不等于聊天数据库已完整独立，消息定位仍需相应的本机微信快照。

缓存默认上限 256 MiB，可改为 512 MiB 或 1 GiB；“清理缓存”只移除本软件的媒体缓存，不清除留存，也不修改微信原件。只有缩略图的消息无法凭空恢复原图。留存图像保存的是可解码的可用版本；特殊微信图片格式可能转为 JPEG。

下载的表情按账号与内容指纹去重，计入上述缓存上限；“复制留存”模式同时保留原始动画，清缓存不影响留存。本地加密表情使用当前账号专用解码信息，商店表情按包 ID 和原图 MD5 精确定位，只读取所需范围，不把缩略图冒充原图。取图不上传聊天文字或联系人信息，不使用模型；媒体 URL 与解密参数不传给网页、不写入缓存文件。本地和远程表情均校验格式、像素数与消息内的内容 MD5；远程取图另限制文件大小、并发和耗时，禁用代理和重定向、拒绝非公网目标，失败短暂冷却，防止重复请求。

媒体通过账号、会话和完整消息身份定位，前端使用同源受控接口，不接收任意本机路径。账号清理同时清理本软件所属的媒体数据。

## AI 可以分析什么

主动聊天助手与“分析与建议”共用媒体读取链路，支持图片、表情贴纸和视频。主动助手从最近 20 条消息选择媒体；逐条分析从截至目标的最近 100 条消息选择媒体，并优先目标。单次最多 3 条媒体、6 张图像、合计 6 MiB。视觉模型收到实际图片数据，先生成有来源的观察，再与聊天文本一起提供给助手或逐条分析。

- 图片和贴纸会转换为有大小限制的图像。动态图片仅分析首帧；聊天助手读取动态表情时按播放时间均匀抽取最多 4 帧（跳过几乎相同的帧）并标明时间点，“分析与建议”仍只取首帧。原有文本内的 Unicode 表情和 `[捂脸]` 这类微信小表情保持文字输入。
- 视频最多抽取 3 帧，标明采样时间；不等于看完完整视频，也没有分析音轨。
- 语音仅使用可读取的微信转写，保留转写来源，不声称听过原音。
- 原始媒体与 base64 不写入助手对话或上下文数据库；观察摘要可能作为助手上下文保存在本机。临时观察缓存按账号、联系人、模型及媒体内容区分。
- 只有支持视觉输入的生成模型才能读取图像；失败时上下文明确标记资源不可读或视觉模型读取失败，助手不得根据占位符猜测媒体内容。
- 逐条任务排队期间，媒体目标可能已离开最新窗口；系统按被冻结的原消息位置重新核对账号、联系人和消息身份，不因窗口滚动而漏掉已登记目标。

### 聊天助手资料中的表情

聊天助手读取的聊天资料里，每条表情写成 `[表情#3f2a9c「晚安」·抹茶旦旦]` 或 `[表情#3f2a9c：柴犬歪头眨眼]`，不再是统一的占位符：

- **编号**：表情图片内容 MD5 的前 6 位，同一编号就是同一张图，助手可以据此统计谁常发哪张表情。编号由 Core 按消息从微信本地记录读取，插件按消息保存，之后不再重复读取。
- **官方文字**：商店表情消息自带的配字，以及本机微信表情库里已安装表情包的配字和包名。没有安装的表情包只有消息自带的配字。
- **画面概括**：没有官方配字的表情，由后台任务“识别表情”用当前生成模型（需支持看图）按几帧写一句不超过 40 字的概括。打开聊天助手或每次回答完成后，若当前会话还有未识别的表情，就按使用次数从多到少识别，每次最多 100 种，余下的下次继续；用户提问进行中时识别暂停。同一张图在同一账号内只识别一次，各好友共用结果；某个模型连续读不出时，换用其他模型后会重试。识别调用计入“模型调用”。
- **表情帧库**：抽出的帧以小 JPEG 按内容 MD5 保存在本软件该账号的媒体目录（`stickers/`），不计入缓存上限，“清理缓存”不删除，清理账号时一并删除。原图之后被微信清理或 CDN 链接过期，仍可用帧库识别。
- 已有配字或概括的表情不再占用每轮最多 3 条的视觉读取额度；尚未识别的表情仍可在最近 20 条内被本轮读取。

概括是视觉模型对画面的有限描述，不是发送者自述；表情含义仍需结合上下文判断。

这些观察不是发送者自述，也不能用人脸推断人格、身份、好感或敏感属性。本次没有改变独立的消息情绪／人物画像分析流程，也没有批量分析全部历史媒体。

2026-10-13 已将表情包纳入主动助手及“分析与建议”的视觉观察。使用当前应用配置和合成测试图验证了真实视觉接口能读取图形、颜色与文字；测试未使用真实聊天或媒体。

## 开发验证

播放需要 `silk-python`，图片缩放使用 Pillow，微信特殊图像及视频抽帧使用独立 FFmpeg 工具。依赖版本在 `python-requirements.lock.txt`，来源见 `THIRD_PARTY_NOTICES.md`。测试素材使用程序生成的图像、音频、视频，不提交真实联系人或媒体。
