# 需求状态与待办清单

更新：2026-11-02（Asia/Tokyo）。本清单维护免费开源候选的实现与验收状态，并单独列出后续 Pro 规划；发布状态以最终候选源码、安装包和实际验证记录为准。

本清单对照 `docs`、当前源码和已有验证记录整理；仅通过源码或合成测试的项目不连带签收安装版、真实资料质量或公开发布。

- **已实现**：当前源码已有对应能力；不等于所有真实场景或发行环境已验收。
- **待实现**：原需求中已确定、但当前还缺少的功能。
- **开发中**：工作区已有新实现，但尚未取得该阶段的完整验证结果。
- **待验收**：已有实现或合成测试，仍缺相应真实环境的独立验收记录。
- **后续提案／待决定**：研究方向或原讨论中的建议，不自动算作首版漏交付，也没有在本次确定优先级或交付日期。

## 已有实现，尚待独立验收

以下是需要补齐记录的验收事项；本次没有执行它们。真实发送、删除及私人资料操作仍按各项当次授权范围进行，不由清单自动触发。

- [ ] VALID-01：外部聊天导入——用不同来源的真实截图／长截图／录屏覆盖字号、主题、日期条、引用、长气泡、画面重叠及快滚；核对文字、发言人、边界、顺序、重复／漏消息和证据定位，并测量与交互助手并行时的排队及资源占用。见[首版验证前提](external-chat-import-requirements.md)。
- [ ] VALID-02：自我剖析——在无开发环境、无 DGX 专用配置、无预建私人库的干净 Windows 发行环境，完成模型准备、建库、首批试用、全库覆盖、校正、断网恢复、暂停重开和增量升级；记录最低支持设备上的时间、内存和磁盘占用。见[自助建库验收](personal-reply-style-requirements.md)。
- [ ] VALID-03：表达与分析质量——按相同场景和模型对照基线、本人资料与跨联系人 RAG，完成用户盲评，核对语气、回应内容、关系分寸及事实隔离；另验证好友分析和助手摘要的真实效果、用量准确度与延迟。合成测试和 embedding 检索 benchmark 不替代这些产品质量验收。
- [ ] VALID-04：MCP——在指定本机 AI 客户端验证稳定连接、无界面启动及 GUI 共存；验证资料查询、分析调用和高影响删除本机确认；同时核对免费版工具目录与能力中没有微信发送。见[MCP 实施状态](mcp-plugin-implementation.md)。
- [ ] VALID-05：旧数据与运行环境——验证真实旧账号的助手会话重建、模板与知己分析资料迁移；核对安装包内插件、网关和 OpenCode 运行，以及仍缺的真实桌面前台焦点／窗口生命周期验证。不能仅用源码 staging 或隐藏窗口测试签收。
- [ ] VALID-06（后续 Pro）：双机微信节点、消息同步和断线恢复验证另行执行，不属于首版免费功能；不自动迁移真实账号。
