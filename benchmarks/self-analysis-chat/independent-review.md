## 标准

- query 的最后一条来信应给本人留下真实的下一步回应；目标偏好、可用性、关系和限制须在可见前文中成立。
- source.reply 应回应自己的前文；可提出新安排，不得挪用 query 的人物、义务、时间或地点，或与自己的前文矛盾。
- grade 2 表示核心沟通动作、立场和关键限制可以直接迁移；不要求日期、话题、选项数量等表面细节相同。grade 1 表示核心方向成立但关键支持较弱；不设固定数量配额。
- grade 0 包含不完成目标动作的样例，未必都危险。跨家族样例仍可能相关，不能用 familyId 代替判断。
- 标签只规定可迁移的回应方式，不授权复制历史事实。文本未给本人能否带物品等事实时，不要求模型凭空知道。

## 跨家族检查

全量逐条阅读后，集中审了工作求助、有限帮忙、改约、取消状态、借还、倾听与建议、话语伤害、保密许可、本人舒适边界、确认与纠正、回复欠账等相邻动作池。318 个明确的 query/source 增标裁定覆盖 56 个 query，理由和精确文本摘要哈希交给作者合并；正例一经加入，应从同 query 的硬负例中移除。

例如：贵重礼物拒收、未证实归责先核对、本人伤害对方后的道歉、采用最新明确纠正、歧义所指先澄清、只倾听不代办、只承担已承诺范围等，可以跨不同话题保持强相关。不同渠道或状态只标部分相关，例如不聊天与不登门、尚未取消与尚未答应出席、借款已逾期与物品尚待使用。

没有按家族名批量假定等价：本人拒绝被叫昵称，与本人应停止给对方起外号，角色相反；对方希望换个话题，与对方希望不再联系休息，许可不同；等待对方确认，与本人承诺稍后答复，也不能只因“待定”二字就标为完整同动作。

## 最终核验与限制

冻结版本通过 evaluator 的账户、来源、时间、排除约束校验；硬负例与正例不冲突；160 个 query、480 个 input 与 480 个 reply 各自无完全重复，query 整段未出现在候选中，reply 也未出现在其 input 中；全部 query 和 input 的最后一行均为对方来信，text=input。60 个虚构历史联系人各八段，query target 与历史联系人独立，10 个 dev / 30 个 test 家族。

没有穷举 160×480=76,800 个 query/source 对；定向池之外仍可能有相关遗漏，因此这不是穷尽的人类金标。当前最长 query 105 字符、input 74 字符，主要为二到四条短消息，不检验长历史及 512 token 尾截断质量。本集由 AI 代理编写与审查，测量的是合成语境检索，不能据此证明真人语气或实际回复质量。审查结束前没有运行正式质量评分；不以 test 检索表现反向修标签。后续若发现错误，必须另建版本、说明差异并完整重跑。
