# 中文私聊情境检索合成评测集

状态：已冻结，正式跑分前固定数据与标签。旧版自由生成批次全部撤回，不得复用旧标签。

## 用途与来源

本集用于比较本地中文聊天情境检索：当前来信适合参考哪段本人过去的回复情境。评价可迁移的沟通动作、关系分寸和边界，不评价最终回复是否像真实用户，也不评价回复生成质量、事实记忆或发送行为。

全部数据和初始标签由 AI 代理编写，配置的本地语言模型辅助起草，再由其他 AI 代理在不知道被测检索结果的情况下交叉复核。没有真实用户、真实聊天、真实联系人、真人资料或人类标注。“独立复核”指不同 AI 代理复核，不表示人类人工验证。被测 BGE / Qwen embedding 模型不参与标签编写，不接收 qrels。本集的结果不能直接推广为真实私人聊天效果或个人风格还原能力。

## 组成与划分

实际包含 40 个情境家族、160 条查询、480 条历史候选。每家族包含 4 种容易混淆的沟通动作；每种动作初稿先取两条强相关和一条弱相关样例，而非一个主题只有一种意图。独立复核按实际沟通兼容性升降级及补跨家族相关，不维持每查询固定的 2/2/1 配额。所有候选进入同一全局检索池，不按家族、类别、切分或标签过滤。

覆盖邀约、改约、工作、钱款、互助、安慰、失落、祝贺、感谢、道歉、冲突、回复节奏、昵称与亲密程度、隐私许可、建议边界、玩笑、组织活动、旅行、数字时间、位置、含糊信息、借还物品、照护、推荐、迟复、收尾与取消等。含反话、否定、省略、多轮、emoji 和中英夹杂；负例含同主题异动作、同情绪但相反许可或边界。

固定种子 `20261018` 按家族抽取 10 个 dev 家族和 30 个 test 家族，分别 40 / 120 条查询。同一家族不分散到两个 split。不同家族有意保留相邻沟通行为，以检验跨话题迁移；按家族划分不表示语用行为完全不重叠。候选不随 split 隔离；测试标签冻结后不用于调参。

## 可见文本与检索输入

候选 `input` 是历史回复前的可见聊天语境，截止于对方的新来信；`text` 必须逐字等于 `input`。`reply` 是紧接该来信的本人下一条回复，仅供标签评审与协议指定的生产式回复去重，绝不进入词项或向量编码。查询 `text` 是新的聊天语境，也以仍待本人回应的对方来信结束，不附加测试者回复指令。影响标签的关系、偏好、否定、许可、时间、金额和边界必须有可见证据，不能仅从 metadata 推断。

canonical 正文统一为行首 `本人：` / `对方：`。主评测按 [protocol.json](protocol.json) 仅移除查询行首角色标记，保留正文和顺序，以模拟当前生产查询拼接；候选仍为生产式带角色语境。另用同一候选和 qrels 保留查询角色做表示消融，其结果不用于主模型选择。

排序只可使用正文、`contactId`、`timeMs`。`familyId`、`caseId`、`category`、`tags`、`challengeTags`、`qrels`、`hardNegativeIds`、`annotationRationale` 和起草种子全部禁止用于排序或编码。回复仅可用于固定的去重规则，不可计算相关度。

## 标签定义

- **2，强相关**：最新来信需要的回应动作、本人立场和必要人际限制兼容，可迁移表达。具体人物、物品、地点和日期可以不同，历史具体事实不可照搬。
- **1，弱相关**：主要回应动作兼容，没有关键否定、同意或边界矛盾，但缺少一项使参考不够具体的上下文，或仅覆盖回应的一部分。
- **0，不相关**：不适合迁移当前目标动作。仅同主题、同情绪、出现相同词不足以相关；相反许可、立场、持续性边界或承诺通常为 0。0 也可能仅遗漏应做动作，不表示每条负例都危险或语言有问题。

`qrels` 仅显式存 grade 1 / 2，未列候选按 0 计分。`hardNegativeIds` 是预设的动作不匹配例，不是全部 0 的完整清单，不能作为排序输入。`annotationRationale` 解释最新来信与可见限制。

跨家族盲审会补充发现的相关样例，但并没有由人类穷尽标注 160×480 每个组合。未发现的兼容样例可能造成假负例，需结合强相关命中、分类切片和置信区间解释，不把分数当绝对真值。

## 时间、联系人与局限

时间与联系人全部虚构。候选时间从 2026-09-01 开始按家族及样例确定排列，全部早于 2026-10-18 的查询；ID 使用固定种子打乱。文件中的毫秒值是时间约束依据，不使用运行时日期。按 `(候选 ID 数字部分 - 1) mod 60 + 1` 固定映射至 60 个虚构联系人，完整候选池每人八段跨场景历史；映射事先确定，不依赖标签或模型结果。查询使用独立 target 联系人 ID，因此主要测跨联系人迁移，未验证同联系人加权的收益。每联系人最多两条及回复去重规则保留；约束导致的可行召回上限应单独报告，不能为得到 100% 修改标签。

共同合成作者体系仍可能引入作者偏好、表达习惯和模板关联。虽然改变表面话题，样例仍可能比真实聊天更短、更明确、更规整。联系人分配仅用于施加检索多样化约束，没有构建一套连贯的人物关系史；不覆盖长历史噪声、媒体解析、真实账户切换或消息缺失。合成检索结果不等于真实用户的满意度。
